# EEG-Based Motor Intention Classification Using Machine Learning and Deep Learning

This repository presents a comprehensive framework for EEG-based motor intention classification using data acquired from the EMOTIV EPOC+ Brain–Computer Interface (BCI) system. The project focuses on decoding neural activity associated with motor intentions, including left-hand movement, right-hand movement, and resting states, through advanced machine learning and deep learning techniques.

The original framework was developed in 2023 and implemented traditional machine learning algorithms such as Support Vector Machine (SVM), Random Forest (RF), XGBoost, Decision Tree, K-Nearest Neighbors (KNN), and Logistic Regression, alongside deep learning architectures including Convolutional Neural Networks (CNN) and Long Short-Term Memory (LSTM) networks. The EEG data were preprocessed, normalized, and transformed into meaningful features using statistical, frequency-domain, and signal-processing techniques to improve classification performance.

To align with recent developments in artificial intelligence and neural signal decoding, the repository has been extended with state-of-the-art architectures including Transformer Networks, Attention-Based Models, and Graph-Inspired Neural Networks (GNNs). These modern approaches are designed to capture complex spatial, temporal, and contextual relationships within EEG signals, providing a more powerful framework for Brain–Computer Interface applications.

The repository includes modules for data cleaning, preprocessing, feature extraction, feature selection, model training, performance evaluation, confusion matrix generation, ROC curve analysis, feature importance visualization, and comparative benchmarking across all implemented models.

This project aims to contribute to the advancement of Brain–Computer Interfaces, neurorehabilitation systems, assistive technologies, and intelligent human–computer interaction. It serves as a research-oriented platform for students, researchers, and practitioners interested in EEG signal processing, machine learning, deep learning, neural engineering, and next-generation BCI technologies.
